# Latos Hue 更新日志

桌面软件 **Latos Hue**（修图助手）的版本记录。版本号规则：开发阶段按 `0.x.0` 记录，**首个公开发布的版本为 1.0.0**。
本文件记录的是软件本身；Lightroom 插件与服务端（LrMCP）有自己的版本线，见仓库根目录的 `CHANGELOG.md`（当前 0.15.0）。

> 下面 0.1.0–0.17.2 都是开发中的内部版本，全部完成于 2026-11-03，**尚未发布**。每一项的详细过程、实测数字和未解决项见 `app/DEV_NOTES.md`。

## 0.17.2 — 启动界面最短停留
- **启动界面至少停留 3.5 秒（从窗口系统启动算起）：** 以前主界面 1 秒内就加载完，启动界面一闪而过看不到（计时实测：主界面 0.97 秒准备好）。现在即使主界面早就准备好，也让丝带图标、名称和版本号完整露出一下再切换；交接在后台线程里等，不阻塞主流程。看门狗（20 秒）与“没有启动窗口”的情况不等待。代价是每次打开多等约 2.5 秒（用户选定 3.5 秒）。
- 测试：app 新增 2 个用例（最短停留的等待与不等待）。**真机未验证：** 真窗口里启动界面实际可见的时长与观感。

## 0.17.1 — 窄窗口布局修复
- **窗口不宽时字不再挤变形：** 以前窗口窄一些，顶栏按钮（导入、导出、AI 挑片、设置、新对话）会被挤成竖排，状态提示和中间栏的“并排 / 多版本 / 预览清晰度 / 适合窗口”也会被挤乱。现在按钮和标签文字一律不换行；顶栏放不下时自动折成两行，状态提示放不下就用“…”缩略（鼠标放上去能看完整内容）。
- **三栏宽度会跟着窗口缩放：** 左右栏在窄窗口里自动变窄；窗口很窄时“并排”的两张图改成上下排列。宽窗口的外观不变。
- **窗口最小尺寸调为 960×620**，不会再被缩到没法用。
- 设置、环境检查、导出、导入对话框在窄窗口下也查过，没有溢出。
- 新增自查脚本 `app/tests/ui_layout_check.py`，按 640–1920 多个宽度出图并检查是否溢出（截图在 `app/docs/layout_*.png`）。功能没有改动。

## 0.17.0 — 安装包
- **双击安装：** 新增安装包 `LatosHue-Setup-0.17.0.exe`（约 37 MB），不需要管理员权限，默认装到 `%LOCALAPPDATA%\Programs\Latos Hue`；开始菜单快捷方式、可选的桌面快捷方式（默认不勾）、装完可直接运行。快捷方式指向窗口版，不会弹黑窗。构建：`powershell -ExecutionPolicy Bypass -File build_app.ps1 -Installer`。
- **顺手装好 Lightroom 插件：** 把插件放进 `%APPDATA%\Adobe\Lightroom\Modules\LrMcp.lrplugin`（Lightroom 自动加载），已有同名插件就整个换新，结束页提示“请重启 Lightroom”。不登记到 Claude / Codex（软件自己启动 AI）。
- **卸载：** 删除程序、快捷方式和上面这个插件文件夹；设置、经验笔记等个人数据（`%USERPROFILE%\LrMcp`）默认保留，卸载时会问“是否同时删除”，默认选“否”，静默卸载一律不删；不会动你的照片文件夹。
- 安装前提示缺少 WebView2 运行库（只提示和给下载页，不自动下载）；安装说明用大白话写明开源、非 Adobe 产品、照片只在本机处理、预览图会发给你选的 AI 服务。
- 测试开关：`/PLUGINDIR=<路径>` 改插件目标目录，`/NOPLUGIN` 跳过插件，便于不碰真实 Lightroom 地验证。
- 没有代码改动；测试：app 899 个通过、1 个跳过，server 413 个通过。

## 0.16.0 — 免 Python 打包
- **不用装 Python 就能运行：** 新增 `build_app.ps1`，把软件打成一个程序目录 `build\app_dist\LatosHue\`（约 76 MB，里面有 `LatosHue.exe` 窗口版和 `latoshue-helper.exe` 辅助版，WebView2 运行库仍用系统自带的）。这一步只做打包并验证能运行，安装包、卸载、插件安装是下一步。

- **统一入口 `app/run_latoshue.py`：** 无参数打开界面；上面三个子命令；`--selftest` 不开窗口，检查模块、资源、server 包、辅助程序、数据目录，通过退出码 0。`python app/main.py` 和 `运行模板.bat` 照旧。
- 用户数据仍在 `~/LrMcp/`，没有变化。
- 测试：新增 17 个（命令构造的开发/冻结两种分支、资源路径、入口分发、冻结后配置里不再出现 python 或 .py、自检）。

- **设置：** 新增“更新”一栏的开关“启动时检查新版本”（默认开；说明写明只提示、不自动下载安装、只访问 GitHub、不发送个人信息）；关掉后启动时不发任何网络请求。“关于”里新增“检查更新”按钮：点了立即检查（忽略缓存，也不受那个开关限制，因为是你主动点的），显示“已是最新版本 / 有新版本 x.y.z / 暂时无法检查（可能没联网）”。设置新增 `check_updates`（布尔，默认 True；旧设置文件没有这一项也能正常读取）。

## 0.13.1 — 自动启动后的宽限期与更清楚的超时提示
- **启动宽限期：** 软件自动启动 Lightroom（或发现它刚开着、正在等插件连上）后的前 90 秒，后台的“长时间连不上就换端口重建通道”暂停——刚启动时插件还没加载，频繁换端口既没用，也看不出发生了什么。Lightroom 一连上、宽限期满、或没开自动启动时，行为与以前完全一致。超时仍是 120 秒，所以 90–120 秒之间恢复自动换端口属预期。
- **超时提示改成大白话并带排查线索：** “Lightroom 已经打开，但插件还没连上。请在 Lightroom 的 文件 → 增效工具管理器 里确认 LrMCP 显示“已安装并正在运行”，必要时点“重新载入增效工具”。”顶栏提示允许折成多行，能看全这句话（沿用原有 `lr_launch` 事件）。
- **Codex 来源去掉“实验性”标记：** 贡献者 Galio1991 在 Windows + Lightroom Classic 15.0（测试目录）上完成了真机验收（PR #5、#6 的验证报告）：读取预览、确认写入与撤销、拒绝路径、环境变量传递、模型自行调用 `lr_restore`。设置里不再显示“（实验性，未经真机验证）”，隐私提示（预览会发送至所选 Codex 服务）保留；默认来源仍是 Claude。命令行黑窗口只做了采样观察，不能排除短暂闪现。
- 测试：app 721 个通过、1 个跳过；server 413 个通过。界面截图 `app/docs/lr_launch_timeout.png`（假数据）。
- **真机未验证：** 首次连不上的原因仍未查明（曾有一次自动拉起 Lightroom 后 5 分钟没连上，后来同样流程 12 秒就连上了）；宽限期只是避免期间乱换端口，不是根因修复。

## 0.13.0 — 自动启动 Lightroom 与启动界面
- **自动启动 Lightroom（设置里的开关，默认关）：** 设置新增"Lightroom"一栏——"自动启动 Lightroom"开关，说明为"打开软件时自动在后台启动 Lightroom（最小化，不会抢走你当前的窗口）；已经开着就不会重复启动；关闭本软件时也不会关闭 Lightroom"。开启后，软件启动时用 `tasklist`（隐藏窗口）查 Lightroom.exe 是否在运行，没在运行才启动，启动用 `STARTUPINFO` + `SW_SHOWMINNOACTIVE`（最小化、不抢焦点、不弹控制台）。之后沿用原有连接判定等插件连上（插件每 2 秒扫描，最多等 120 秒）；顶栏显示"正在启动 Lightroom…"，连上后恢复"Lightroom 已连接"，找不到或超时只给温和提示（"没找到 Lightroom，请手动打开"等），不报错、不崩溃。
- **Lightroom 位置：** 默认自动查找（注册表 App Paths、`Program Files\Adobe\Adobe Lightroom Classic*`）；也可在设置里点"选择文件"自己点选 Lightroom.exe，"自动查找"改回自动。路径只来自这次文件对话框点选，页面不能直接传路径。**安全：** 只启动固定的 Lightroom.exe，不带任何命令行参数；路径必须是本机盘符（不接受网络路径）、文件真实存在、文件名为 Lightroom.exe，否则整体拒绝。
- **启动界面：** 主界面出现前显示一个小启动窗口（圆角深色底、丝带图标、"Latos Hue 修图助手"、版本号、一行进度文字：正在检查环境 / 启动后台服务 / 正在连接 Lightroom / 载入界面…），主界面准备好后自动关闭并显示主窗口。主窗口先隐藏加载，启动界面里的所有窗口调用都在后台线程，不阻塞主流程；20 秒看门狗兜底，创建启动窗口失败则直接显示主窗口，绝不会卡在启动界面。环境变量 `LRAPP_NO_SPLASH=1` 可关闭启动界面。
- **图标：** 窗口与任务栏图标改用丝带图标（`app/web/assets/latos-hue-ribbon.ico`，经 `webview.start(icon=...)`；启动界面用内嵌的 192 px 丝带 PNG）。
- 测试：app 710 个通过、1 个跳过（原 645 个保持通过，新增 65 个）；server 413 个通过、0 个跳过。界面截图 `app/docs/splash.png`、`settings_autolr.png`、`lr_launch_starting.png`、`lr_launch_notfound.png`（假数据）。
