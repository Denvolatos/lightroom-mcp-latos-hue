## 实验 1：最小插件能否加载（2026-11-01，Lightroom Classic 15.2.0，Windows）

**做法**：`plugin/lrmcp.lrdevplugin`，通过 增效工具管理器 → 添加 载入；只读。

| 项目 | 结果 |
|---|---|
| `LrSdkVersion = 15.0` + `LrSdkMinimumVersion = 6.0` | ✅ 15.2 可加载 |
| `LrForceInitPlugin = true` 的 `Init.lua` | ✅ 添加插件时运行；**冷启动是否运行：待验证** |
| 菜单项（图库 → 增效工具附加功能） | ✅ 可点击，输出正常 |
| 版本 | 15.2.0，build 202602111402-ec4112e8 |
| 沙箱 | `os.getenv`=nil、`os.execute`=nil、`io.open`=function、`io.popen`=function（`io.popen` 是否真可用：待验证，不依赖） |
| 当前目录 | 测试目录，6 张照片 |
| 日志位置 | `%LOCALAPPDATA%\Adobe\Lightroom\Logs\LrClassicLogs\<名字>.log`（手册写 `.txt`，实际是 `.log`） |
