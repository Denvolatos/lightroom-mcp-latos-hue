# Latos Hue 1.1.0 + LrMCP 1.1.0 — 多版本、批量复用、图库换目录、首次自己选 AI / Versions, edit reuse, folder browsing, first-run AI choice

## 中文

这是一个功能版本。Latos Hue（桌面软件）和 LrMCP（Lightroom 插件与 MCP 服务）继续使用同一个版本号、同一个发布，两个安装包都是 1.1.0。
这一版合并了贡献者 **Galio1991** 的 PR #7，并包含原计划作为 1.0.3 的修复（1.0.3 没有单独发布过，这个版本号不再使用）。

### Latos Hue 1.1.0（普通用户装这个）

新功能：
- **多版本：** 中间栏的“多版本”页可以用了。点“保存当前”把照片现在的样子起名存下来；之后可以并排看“已保存版本”和“当前”，以及两者差在哪些参数上。点“应用版本”会先列出要改的每一项，你确认后才写入；应用后可以撤销。保存版本只记参数，不改照片。
- **批量复用单张调整：** 在“本次调整”里对一次已生效的滑块调整点“复用”，把同样的加减量用到其他选中的照片上（一次最多 10 张）。先预演（此时什么都没改），确认后才写入，写完可以整批还原。裁剪、拉直、曲线不能批量复用。
- **图库可以换目录：** 点图库上方的“换目录”，可以浏览电脑上任意一个照片文件夹（含子文件夹），不必先导入。浏览只是读取，不移动、不复制、不修改你的文件；对还没进 Lightroom 目录的照片点“加入 Lightroom”是原地添加。AI 修图的修改保存在 Lightroom 目录里、可以撤销，原片文件不会被改动。“导入”复制出来的副本仍然只存到设置里的照片工作文件夹。
- **第一次由你自己选 AI：** 全新安装后，“环境检查”会请你在 Claude 和 Codex 之间选一个，并写明每个现在的状态（已安装并已登录 / 已安装但未登录 / 未安装）。你选之前软件不会启动任何 AI，图库、导入、导出、预设照常可用。**从旧版本升级的用户不受影响**，沿用原来选的 AI。
- **重连后自动刷新图库**；**更清楚的预览错误提示**（说明是没连上、正忙，还是这次读取没成功）。

修复与改进：
- **覆盖安装 / 卸载时不再“拒绝访问”：** 1.0.2 没有修到真正的原因。软件会把自己的运行库目录加入 Windows 的“DLL 搜索路径”，Windows 又把它带给软件启动的 Lightroom，所以 Lightroom 仍然加载并占着软件目录里的 `VCRUNTIME140.dll` 等文件。现在软件在启动 Lightroom 的那一瞬间临时撤掉这个搜索目录，Lightroom 不再占用软件目录里的文件。
- **同时开着多个 AI 会话时反应更快（预期，待真机确认）：** 插件向每个会话询问新命令的等待时间从 10 秒缩短到 1 秒。
- **不再执行已经等超时的命令**；**AI 正在工作时，软件界面上的写入（应用版本、复用、整批还原等）会提示你先等它完成**。

怎么升级：
1. 下载 `LatosHue-Setup-1.1.0.exe`，核对下面的 SHA-256。
2. **先关闭 Latos Hue 和 Lightroom**（旧版拉起的 Lightroom 还占着文件，这一步很重要）。
3. 在你自己的资源管理器里双击运行 `LatosHue-Setup-1.1.0.exe` 覆盖安装，设置和数据都会保留。如果安装程序仍提示文件被占用，点“重试”之前请先确认 Lightroom 已经关闭。
4. 装完重启 Lightroom，让插件更新到 1.1.0。

系统要求：Windows 10 / 11；已安装 Lightroom Classic；已安装并登录的 Claude Code 或 Codex 命令行。

### 已知限制
- 只支持 Windows；需要 Lightroom Classic 和已登录的 Claude Code 或 Codex 命令行。
- 安装包**没有代码签名**，Windows SmartScreen 可能提示“未知发布者”，可点“更多信息”→“仍要运行”。
- 下列情况尚未在真机上充分验证：Windows 125% / 150% 缩放下的外观；100 张以上的大批量导入和真实存储卡；原始尺寸的 16 位 TIFF 导出；多个 AI 会话同时连接时 1 秒轮询的实际改善。
- 导出只有 JPEG 和 TIFF，没有 PNG；没有 Mac 版；蒙版（局部调整）不能由 AI 修改，也不在保存的版本里。
- 批量复用一次最多 10 张，只支持滑块（裁剪、拉直、曲线不行）。
- 只在 Windows 11 + Lightroom Classic 15.x 上测过。软件自动启动 Lightroom 后，插件偶尔连接较慢；超过两分钟还没连上时，软件会提示你到 Lightroom 的「文件 → 增效工具管理器」里检查 LrMCP。

### 给 Claude Code / Codex 直接使用 MCP 服务的人
`LrMCP-Setup-v1.1.0.exe` 是单独的 Lightroom 插件 + MCP 服务安装包，不含桌面软件。这一版服务端把插件轮询的等待时间从 10 秒缩短到 1 秒（预期改善多会话同时连接时的响应，待真机确认），并且不再把调用方已经等超时的命令交给插件执行；工具和使用方式不变。升级后在 Lightroom 里重载一次插件（文件 → 增效工具管理器 → 重新载入插件，或重启 Lightroom）即可。只想修图的普通用户不需要装它。

## English

A feature release. Latos Hue (the desktop app) and LrMCP (the Lightroom plug-in and MCP server) keep sharing one version number and one release; both installers are 1.1.0.
It merges pull request #7 by the contributor **Galio1991** and contains the fix that was planned as 1.0.3 (1.0.3 was never released; that number is not used).

### Latos Hue 1.1.0 (most people want this one)

New:
- **Versions:** the "多版本" (versions) page in the middle column now works. "保存当前" saves how the photo looks now under a name; later you can compare "saved version" and "current" side by side and see which settings differ. "应用版本" first lists every setting it would change and writes only after you confirm; you can undo it afterwards. Saving a version only records settings, it does not change the photo.
- **Reuse one edit on other photos:** in "本次调整" (this session's changes) click "复用" on a slider change that was applied, and the same relative amounts are applied to the other selected photos (up to 10 at a time). You get a dry run first (nothing is changed yet), it writes only after you confirm, and the whole batch can be restored. Crop, straighten and curves cannot be reused in a batch.
- **Browse any photo folder:** "换目录" above the gallery lets you browse any photo folder on your computer (with subfolders) without importing first. Browsing only reads; nothing is moved, copied or modified. "加入 Lightroom" adds photos that are not in the catalog yet in place. The AI's edits are stored in the Lightroom catalog and can be undone; the original photo files are not changed. Copies made by "Import" still go only to the photo work folder set in Settings.
- **You choose the AI the first time:** after a fresh install the "environment check" asks you to choose between Claude and Codex and shows the state of each (installed and signed in / installed but not signed in / not installed). The app starts no AI before you have chosen; gallery, import, export and presets work as usual. **People upgrading from an older version are not asked**; the AI they chose stays.
- **The gallery refreshes itself after Lightroom reconnects**, and **preview errors are clearer** (not connected, busy, or this read failed).

Fixes and improvements:
- **No more "access denied" when installing over an existing copy or uninstalling:** the 1.0.2 fix did not reach the real cause. The app adds its own runtime folder to Windows' DLL search path, and Windows hands that path to the Lightroom the app starts, so Lightroom still loaded and locked `VCRUNTIME140.dll` and other files from the app folder. The app now removes that search folder at the moment it launches Lightroom, so Lightroom no longer locks files in the app folder.
- **Faster with several AI sessions open (expected, still to be confirmed on a real machine):** the plug-in's wait for new commands from each session went from 10 seconds to 1 second.
- **Commands whose caller already gave up are no longer executed**, and **while the AI is working, writes from the app's own interface (apply version, reuse, restore batch, ...) ask you to wait until it has finished**.

How to upgrade:
1. Download `LatosHue-Setup-1.1.0.exe` and compare the SHA-256 below.
2. **Close Latos Hue and Lightroom first** (a Lightroom started by an older version still holds the files; this step matters).
3. Double-click `LatosHue-Setup-1.1.0.exe` from your own File Explorer to install over the old version; settings and data are kept. If the installer still says a file is in use, make sure Lightroom is closed before you click "Retry".
4. Restart Lightroom afterwards so the plug-in is updated to 1.1.0.

Requirements: Windows 10 / 11; Lightroom Classic installed; the Claude Code or Codex command line installed and signed in.

### Known limitations
- Windows only; needs Lightroom Classic and a signed-in Claude Code or Codex command line.
- The installer is **not code-signed**; Windows SmartScreen may show "unknown publisher" (click "More info", then "Run anyway").
- Not yet verified well enough on real machines: the look at 125% / 150% scaling; bulk imports of 100+ photos and real memory cards; full-size 16-bit TIFF export; how much the 1-second poll really helps with several AI sessions.
- Export is JPEG and TIFF only (no PNG); no Mac version; the AI cannot change masks (local adjustments), and masks are not part of a saved version.
- Edit reuse handles at most 10 photos at a time and sliders only (no crop, straighten or curves).
- Tested only on Windows 11 with Lightroom Classic 15.x. After the app starts Lightroom automatically, the plug-in can occasionally be slow to connect; if it has not connected after two minutes, the app tells you to check LrMCP in Lightroom's File > Plug-in Manager.

### For people who use the MCP server directly with Claude Code / Codex
`LrMCP-Setup-v1.1.0.exe` is the stand-alone installer for the Lightroom plug-in and the MCP server (no desktop app). In this release the server answers the plug-in's poll after at most 1 second instead of 10 (expected to improve response with several sessions connected; still to be confirmed on a real machine) and no longer hands the plug-in a command whose caller has already timed out; the tools and how to use them are unchanged. After upgrading, reload the plug-in once in Lightroom (File > Plug-in Manager > Reload Plug-in, or restart Lightroom). If you only want to retouch photos you do not need it.
