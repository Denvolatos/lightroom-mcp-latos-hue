# Latos Hue 1.0.1 + LrMCP 1.0.1 — 统一版本号 / One version number

## 中文

从这个版本起，**Latos Hue（桌面软件）和 LrMCP（Lightroom 插件与 MCP 服务）使用同一个版本号、同一个发布**，每次发布都带两个安装包。项目的 GitHub 仓库同时改名为 **lightroom-mcp-latos-hue**（`https://github.com/Denvolatos/lightroom-mcp-latos-hue`），旧地址会自动跳转。

### Latos Hue 1.0.1（普通用户装这个）
Latos Hue（修图助手）是一个 Windows 桌面软件：导入照片、挑片、让 AI 帮你修图、再导出，Lightroom Classic 在后台当修图引擎，安装时会同时装好 Lightroom 插件。

这次更新了什么：
- **检查更新同时认新旧仓库名：** 为 GitHub 仓库改名做准备，仓库改名后仍能收到"有新版本"的提示。1.0.0 在改名后可能收不到更新提示，请手动安装本版本。
- 检查更新同时认 `v` 和历史的 `hue-v` 两种发布标签。
- 软件"关于"页和安装程序里的项目地址改成新仓库地址。
- 其余功能、界面和已知限制与 1.0.0 相同。

怎么安装 / 升级：
1. 下载 `LatosHue-Setup-1.0.1.exe`，核对下面的 SHA-256。
2. 在你自己的资源管理器里双击运行（不要通过 Claude 桌面版启动）。**已装 1.0.0 的话，直接运行新安装包覆盖安装即可，设置和数据都会保留。**
3. 装完重启 Lightroom。

系统要求：Windows 10 / 11；已安装 Lightroom Classic；已安装并登录的 Claude Code 或 Codex 命令行。

### 已知限制
- 只支持 Windows；需要 Lightroom Classic 和已登录的 Claude Code 或 Codex 命令行。
- 安装包**没有代码签名**，Windows SmartScreen 可能提示"未知发布者"，可点"更多信息"→"仍要运行"。
- 下列情况尚未在真机上充分验证：Windows 125% / 150% 缩放下的外观；100 张以上的大批量导入和真实存储卡；原始尺寸的 16 位 TIFF 导出。
- 导出只有 JPEG 和 TIFF，没有 PNG；没有 Mac 版；"多版本"对比页暂未提供。
- 只在 Windows 11 + Lightroom Classic 15.x 上测过。软件自动启动 Lightroom 后，插件偶尔连接较慢；超过两分钟还没连上时，软件会提示你到 Lightroom 的「文件 → 增效工具管理器」里检查 LrMCP。


### 给 Claude Code / Codex 直接使用 MCP 服务的人
`LrMCP-Setup-v1.0.1.exe` 是单独的 Lightroom 插件 + MCP 服务安装包，不含桌面软件，适合只想让 Claude Code、Codex 等 AI 客户端直接调用的人。**它的版本号从 0.15.0 统一为 1.0.1（与 Latos Hue 同号）；从此每次发布两个安装包使用同一个版本号。** 这次插件和服务端只改了版本号，工具和使用方式与 0.15.0 完全相同。升级后需要在 Lightroom 里重载一次插件（文件 → 增效工具管理器 → 重新载入插件，或重启 Lightroom）。只想修图的普通用户不需要装它。

## English

From this release on, **Latos Hue (the desktop app) and LrMCP (the Lightroom plug-in and MCP server) share one version number and one release**, and every release carries two installers. The GitHub repository is also renamed to **lightroom-mcp-latos-hue** (`https://github.com/Denvolatos/lightroom-mcp-latos-hue`); the old address redirects.

### Latos Hue 1.0.1 (most people want this one)
Latos Hue is a Windows desktop app: import photos, pick the best ones, let an AI retouch them and export. Lightroom Classic works in the background as the editing engine, and the installer also installs the Lightroom plug-in.

What changed:
- **The update check accepts both the new and the old repository name**, so you keep getting update notices after the rename. 1.0.0 may stop seeing them after the rename: please install this version manually.
- The update check accepts both release tag styles, `v` and the historical `hue-v`.
- The project address in the About page and in the installer points to the new repository.
- Everything else, including features, interface and known limitations, is identical to 1.0.0.

How to install / upgrade:
1. Download `LatosHue-Setup-1.0.1.exe` and compare the SHA-256 below.
2. Double-click it from your own File Explorer (not from a shell started by Claude Desktop). **If 1.0.0 is installed, just run the new installer over it; settings and data are kept.**
3. Restart Lightroom after installing.

Requirements: Windows 10 / 11; Lightroom Classic installed; the Claude Code or Codex command line installed and signed in.

### Known limitations
- Windows only; needs Lightroom Classic and a signed-in Claude Code or Codex command line.
- The installer is **not code-signed**; Windows SmartScreen may show "unknown publisher" (click "More info", then "Run anyway").
- Not yet verified well enough on real machines: the look at 125% / 150% scaling; bulk imports of 100+ photos and real memory cards; full-size 16-bit TIFF export.
- Export is JPEG and TIFF only (no PNG); no Mac version; the "multiple versions" comparison page is not available yet.
- Tested only on Windows 11 with Lightroom Classic 15.x. After the app starts Lightroom automatically, the plug-in can occasionally be slow to connect; if it has not connected after two minutes, the app tells you to check LrMCP in Lightroom's File > Plug-in Manager.


### For people who use the MCP server directly with Claude Code / Codex
`LrMCP-Setup-v1.0.1.exe` is the stand-alone installer for the Lightroom plug-in and the MCP server (no desktop app), for people who only want an AI client such as Claude Code or Codex to talk to Lightroom. **Its version number moves from 0.15.0 to 1.0.1, the same as Latos Hue; from now on every release carries both installers under one version number.** In this release the plug-in and server only got the new version number; the tools and how to use them are exactly as in 0.15.0. After upgrading, reload the plug-in once in Lightroom (File > Plug-in Manager > Reload Plug-in, or restart Lightroom). If you only want to retouch photos you do not need it.
