# Latos Hue 1.2.0 + LrMCP 1.2.0 — 照片库：按拍摄日期整理、全库去重、更多排序 / Photo library: date folders, library-wide de-duplication, more sorting

## 中文

Latos Hue（桌面软件）和 LrMCP（Lightroom 插件与 MCP 服务）继续使用同一个版本号、同一个发布，两个安装包都是 1.2.0。

### 新功能（普通用户看这里）
- **导入按拍摄日期整理：** 照片自动放进 `年\年-月-日` 文件夹。日期读照片里的拍摄时间（JPEG、Sony ARW 已在真实照片上验证），读不到用文件修改时间。导入前会告诉你每天几张、几张重复。
- **整个库范围内去重：** 库里任何位置已有内容完全相同的文件（大小和 SHA-256 一致）就跳过，与文件名、所在文件夹无关；同名不同内容自动改名，不覆盖。
- **更多排序：** 拍摄时间、导入时间、名称、大小、星级、旗标、颜色标签、最后修改、是否修过、类型，升序降序都行，会记住你的选择。
- **空库引导。** 
- **删除：** “换目录 / 浏览任意文件夹”和导入时的“分类文件夹名”。旧版的分类文件夹不会被移动，照样显示。

### 其他
- 界面文件拆成多个小文件，使用上没有变化。
- 安装包去掉一项很可能触发 Windows Defender 误报（`Trojan:Win32/Wacatac.H!ml`）的安装设置，1.2.0 安装包 Defender 扫描未发现问题。该原因由对照实验推测，非确证。

### 怎么升级
1. 下载 `LatosHue-Setup-1.2.0.exe`，核对 SHA-256。 2. 先关闭 Latos Hue 和 Lightroom。 3. 运行安装包覆盖安装，设置和数据保留。 4. 装完重启 Lightroom，让插件更新到 1.2.0。

### 已知限制
- 只支持 Windows；需要 Lightroom Classic 和已登录的 Claude Code 或 Codex 命令行；安装包没有代码签名，SmartScreen / Defender 可能提示，点“更多信息”→“仍要运行”。
- 尚未在真机上验证：HEIC / CR3 的拍摄日期读取；照片很多时的性能；Windows 125% / 150% 缩放；Codex 的相关修复。

## English

Latos Hue and LrMCP share one version and one release; both installers are 1.2.0.

**New:** imports go into `year\year-month-day` folders by capture date (EXIF; verified on real JPEG and Sony ARW files; file modified time if no EXIF); de-duplication across the whole library by size + SHA-256 regardless of name or folder; 10 sort keys with ascending/descending and a remembered choice; an empty-library hint. **Removed:** "change folder / browse any folder" and the import "category" name (existing category folders are left alone). The installer drops the `AppMutex` setting that most likely triggered the Defender false positive on 1.1.1 (inferred from a controlled experiment, not confirmed); the 1.2.0 installers scanned clean.

**Upgrading:** close Latos Hue and Lightroom, install over the old version (settings kept), restart Lightroom.

**Not yet verified on a real machine:** capture dates of HEIC / CR3 files; performance on very large libraries; 125% / 150% scaling; the Codex fixes. Installers are unsigned. Windows only. AGPL-3.0-only; not an Adobe product.
