# Latos Hue 1.0.2 + LrMCP 1.0.2 — 修复覆盖安装时文件被占用 / Fix for installer "access denied"

## 中文

这是一个小修复版本。Latos Hue（桌面软件）和 LrMCP（Lightroom 插件与 MCP 服务）继续使用同一个版本号、同一个发布，两个安装包都是 1.0.2。

### Latos Hue 1.0.2（普通用户装这个）

这次修了什么：
- **覆盖安装 / 卸载时报"拒绝访问"或"文件被占用"：** 以前软件自动启动 Lightroom 时，会把软件自己的目录一并传给 Lightroom，Lightroom 就把软件目录里的运行库文件（如 `VCRUNTIME140.dll`）加载进自己的进程并一直占着，之后覆盖安装或卸载软件就会失败。现在软件拉起 Lightroom 时不再传软件的目录，Lightroom 不会再占用软件目录里的文件。
- 其余功能、界面和已知限制与 1.0.1 相同。

怎么升级：
1. 下载 `LatosHue-Setup-1.0.2.exe`，核对下面的 SHA-256。
2. **先关闭 Latos Hue 和 Lightroom**（旧版拉起的 Lightroom 还占着文件，这一步很重要）。
3. 在你自己的资源管理器里双击运行 `LatosHue-Setup-1.0.2.exe` 覆盖安装，设置和数据都会保留。如果安装程序仍提示文件被占用，点"重试"之前请先确认 Lightroom 已经关闭。
4. 装完重启 Lightroom。以后不会再发生。

系统要求：Windows 10 / 11；已安装 Lightroom Classic；已安装并登录的 Claude Code 或 Codex 命令行。

### 已知限制
- 只支持 Windows；需要 Lightroom Classic 和已登录的 Claude Code 或 Codex 命令行。
- 安装包**没有代码签名**，Windows SmartScreen 可能提示"未知发布者"，可点"更多信息"→"仍要运行"。
- 下列情况尚未在真机上充分验证：Windows 125% / 150% 缩放下的外观；100 张以上的大批量导入和真实存储卡；原始尺寸的 16 位 TIFF 导出。
- 导出只有 JPEG 和 TIFF，没有 PNG；没有 Mac 版；"多版本"对比页暂未提供。
- 只在 Windows 11 + Lightroom Classic 15.x 上测过。软件自动启动 Lightroom 后，插件偶尔连接较慢；超过两分钟还没连上时，软件会提示你到 Lightroom 的「文件 → 增效工具管理器」里检查 LrMCP。

### 给 Claude Code / Codex 直接使用 MCP 服务的人
`LrMCP-Setup-v1.0.2.exe` 是单独的 Lightroom 插件 + MCP 服务安装包，不含桌面软件。这次插件和服务端只是版本号同步为 1.0.2，工具和使用方式不变。升级后在 Lightroom 里重载一次插件（文件 → 增效工具管理器 → 重新载入插件，或重启 Lightroom）即可。只想修图的普通用户不需要装它。

## English

A small fix release. Latos Hue (the desktop app) and LrMCP (the Lightroom plug-in and MCP server) keep sharing one version number and one release; both installers are 1.0.2.

### Latos Hue 1.0.2 (most people want this one)

What changed:
- **"Access denied" / "file in use" when installing over an existing copy or uninstalling:** when the app started Lightroom automatically it used to hand its own folder to Lightroom, so Lightroom loaded runtime files from the app folder (such as `VCRUNTIME140.dll`) into its own process and kept them locked; installing over the app or uninstalling it then failed. The app no longer passes its folder to Lightroom, so Lightroom no longer locks files in the app folder.
- Everything else, including features, interface and known limitations, is identical to 1.0.1.

How to upgrade:
1. Download `LatosHue-Setup-1.0.2.exe` and compare the SHA-256 below.
2. **Close Latos Hue and Lightroom first** (a Lightroom started by an older version still holds the files; this step matters).
3. Double-click `LatosHue-Setup-1.0.2.exe` from your own File Explorer to install over the old version; settings and data are kept. If the installer still says a file is in use, make sure Lightroom is closed before you click "Retry".
4. Restart Lightroom afterwards. It will not happen again.

Requirements: Windows 10 / 11; Lightroom Classic installed; the Claude Code or Codex command line installed and signed in.

### Known limitations
- Windows only; needs Lightroom Classic and a signed-in Claude Code or Codex command line.
- The installer is **not code-signed**; Windows SmartScreen may show "unknown publisher" (click "More info", then "Run anyway").
- Not yet verified well enough on real machines: the look at 125% / 150% scaling; bulk imports of 100+ photos and real memory cards; full-size 16-bit TIFF export.
- Export is JPEG and TIFF only (no PNG); no Mac version; the "multiple versions" comparison page is not available yet.
- Tested only on Windows 11 with Lightroom Classic 15.x. After the app starts Lightroom automatically, the plug-in can occasionally be slow to connect; if it has not connected after two minutes, the app tells you to check LrMCP in Lightroom's File > Plug-in Manager.

### For people who use the MCP server directly with Claude Code / Codex
`LrMCP-Setup-v1.0.2.exe` is the stand-alone installer for the Lightroom plug-in and the MCP server (no desktop app). In this release the plug-in and server only got the new version number; the tools and how to use them are unchanged. After upgrading, reload the plug-in once in Lightroom (File > Plug-in Manager > Reload Plug-in, or restart Lightroom). If you only want to retouch photos you do not need it.
