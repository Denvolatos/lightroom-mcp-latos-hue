# LrMCP v0.15.0

## 中文

LrMCP 是 Lightroom Classic 的插件加 MCP 服务，让 Claude Code、Codex 等 AI 客户端能看你选中的照片并小步修改。它也是桌面软件 Latos Hue 背后用的服务端；Latos Hue 有自己的版本和发布（标签 `hue-v*`）。

### 新增了什么
- **许可证改为 AGPL-3.0**（2026-11-03 的提交起；此前已发布的 v0.1.0–v0.14.0 仍是 MIT）。自有源文件都加了许可证抬头，第三方依赖见 `THIRD_PARTY_NOTICES.md`。
- 新增只供桌面软件用的插件命令（**不是 MCP 工具，AI 助手调用不了，工具数仍是 22 个**）：
  - `import_photo`：把电脑上的一张照片以"添加不移动"的方式加进 Lightroom 目录，插件会重新校验路径和格式；
  - TIFF 导出（8 / 16 位，仅桌面软件；`lr_export` 仍只导出 JPEG）；
  - 列出目录里某个文件夹的照片、取缩略图、在 Lightroom 里选中照片；
  - 写入一组白名单参数（供 Latos Hue 的"我的预设"使用，一次修改可用 `lr_restore` 撤销）。
- **升级后需要在 Lightroom 里重载一次插件**（新命令在插件里）。

### 怎么安装
1. 下载下面的 `LrMCP-Setup-v0.15.0.exe`，核对 SHA-256。
2. 在你自己的资源管理器里双击运行（不要通过 Claude 桌面版启动）。安装包没有代码签名，SmartScreen 会提示"未知发布者"。
3. 装完重启 Lightroom 和你的 AI 助手，让它调用 `lr_status`；出问题调用 `lr_doctor`。

也可以从源码安装，见 README 的 LrMCP 部分。

### 已知限制
- 只在 Windows 11 + Lightroom Classic 15.2 上测过；安装包尚未在干净电脑上做过完整的安装/卸载验收。
- 蒙版（局部调整）不能修改；没有 Mac 版。
- 安装包没有代码签名。

## English

LrMCP is a Lightroom Classic plug-in plus an MCP server that lets AI clients such as Claude Code or Codex look at your selected photo and make small, guarded changes. It is also the backend of the desktop app Latos Hue, which has its own versions and releases (tags `hue-v*`).

### What is new
- **License changed to AGPL-3.0** (from the commits of 2026-11-03 on; the already published v0.1.0 to v0.14.0 stay MIT). Own source files carry license headers; third-party packages are listed in `THIRD_PARTY_NOTICES.md`.
- New plug-in commands **for the desktop app only (not MCP tools; an AI assistant cannot call them; the tool count is still 22):**
  - `import_photo`: adds one photo on this computer to the Lightroom catalog as "add, do not move"; the plug-in re-checks path and format;
  - TIFF export (8 / 16 bit; desktop app only; `lr_export` stays JPEG-only);
  - list the photos of a catalog folder, get thumbnails, and select photos in Lightroom;
  - write a set of whitelisted settings (used by Latos Hue's "my presets"; one change that `lr_restore` can undo).
- **After updating, reload the plug-in once in Lightroom** (the new commands live in the plug-in).

### How to install
1. Download `LrMCP-Setup-v0.15.0.exe` below and compare the SHA-256.
2. Double-click it from your own File Explorer (not from a shell started by Claude Desktop). It is not code-signed, so SmartScreen shows "unknown publisher".
3. Restart Lightroom and your AI assistant, then have it call `lr_status`; if something fails, call `lr_doctor`.

You can also install from source; see the LrMCP part of the README.

### Known limitations
- Tested only on Windows 11 with Lightroom Classic 15.2; the installer has not had a full install/uninstall acceptance on a clean machine.
- Masks (local adjustments) cannot be changed; no Mac version.
- The installer is not code-signed.
