# Latos Hue 1.3.0 + LrMCP 1.3.0 — 全新界面：三套主题、新布局、新设置页和“关于”页 / New look: three themes, new layout, new settings and About

## 中文

Latos Hue（桌面软件）和 LrMCP（Lightroom 插件与 MCP 服务）继续使用同一个版本号、同一个发布，两个安装包都是 1.3.0。这一版重做界面的外观和按钮布局，功能和数据不变。

### 新界面（普通用户看这里）
- **三套主题：** 浅色纸感（默认）、夜蓝玻璃、暗室，另有“跟随系统”；字体大小 4 档。
- **新布局：** 左侧图标栏（照片、配方库、导入、导出、AI 挑片）+ 可收起的照片面板 + 大预览 + 右侧调整和聊天；顶栏显示当前照片，连接状态缩成小胶囊。
- **预览按照片真实比例显示**，新增“排列”开关（自动 / 左右 / 上下 / 滑动对比）；**无级缩放**（10%–400%，Ctrl + 滚轮，拖动平移）。
- **面板可拖动调宽，对话框可拖动。**
- **设置页重做**（分栏 + 卡片），新增只读模式开关、清理缓存、生成脱敏诊断包、恢复默认设置；**新增“关于”页**，作者名字可点击打开 GitHub 主页。

### 怎么升级
1. 下载 `LatosHue-Setup-1.3.0.exe`，核对 SHA-256。 2. 先关闭 Latos Hue 和 Lightroom。 3. 运行安装包覆盖安装，设置和数据保留。 4. 装完重启 Lightroom，让插件更新到 1.3.0。

### 已知限制
- 只支持 Windows；需要 Lightroom Classic 和已登录的 Claude Code 或 Codex 命令行；安装包没有代码签名，SmartScreen / Defender 可能提示。
- **新界面目前只在“假数据 + 无窗口浏览器”里验证过，尚未在真实窗口里用真实照片充分验证**；启动画面只跟随系统浅/深；Windows 125% / 150% 缩放；清理缓存后 Lightroom 重取缩略图；诊断包脱敏范围；HEIC / CR3 拍摄日期读取；Codex 相关修复。

## English

Latos Hue and LrMCP share one version and one release; both installers are 1.3.0. This release redesigns the look and the button layout; features and data are unchanged.

**New:** three themes (Paper light, Night-blue glass, Darkroom) plus "follow system", 4 font sizes; a new layout (icon rail, collapsible photo panel, large preview, adjustments and chat on the right); previews shown at the photo's real aspect ratio with an arrangement switch (auto / side by side / stacked / slider compare) and stepless zoom (10–400%); draggable panels and dialogs; a redesigned settings page (read-only switch, clear cache, redacted diagnostics zip, reset to defaults) and a new About page whose author names open their GitHub profiles.

**Upgrading:** close Latos Hue and Lightroom, install over the old version (settings kept), restart Lightroom.

**Not yet verified:** the new UI was verified only with fake data in a headless browser, not yet in the real window with real photos; splash follows system light/dark only; 125% / 150% scaling; Lightroom re-fetching thumbnails after clearing the cache; redaction coverage of the diagnostics zip; HEIC / CR3 capture dates; the Codex fixes. Installers are unsigned. Windows only. AGPL-3.0-only; not an Adobe product.
