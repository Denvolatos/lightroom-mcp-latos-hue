# Latos Hue 1.1.1 + LrMCP 1.1.1 — 切换照片更快、连接更稳、AI 少走弯路 / Faster photo switching, steadier connection

## 中文

这是一个修复版本，没有新功能。Latos Hue（桌面软件）和 LrMCP（Lightroom 插件与 MCP 服务）继续使用同一个版本号、同一个发布，两个安装包都是 1.1.1。

### 真机对比（测试目录 15 张照片，单位秒）
| 操作 | 1.1.0 | 1.1.1 |
|---|---|---|
| 点选一张照片 | 1.0–1.8 | 0.03–0.19 |
| 第一次显示预览 | 4.1 | 1.3 |
| 同一张照片再刷新 | 2.0 | 0.03 |
| AI 改参数后预览更新 | 3.7 | 1.25 |
| 撤销后预览更新 | 2.1 | 0.8 |
| 列出图库 | 1.0 | 0.04 |
| 取 15 张缩略图 | 2.0 | 0.96 |
| 软件启动到“已连接” | 3.8–4.9 | 1.0–1.8 |

### 修了什么（普通用户看这里）
- **切换照片：** 不再强制让 Lightroom 重新切换文件夹；选中后立刻取预览；缩略图不再把切换照片堵在队伍里；点了马上显示“正在切换”。
- **连接：** 导出大图等耗时命令不再被误判成“插件断开”或导致 AI 进程被重启；没装/没登录 Claude 时不再让整个 Lightroom 连接显示断开；软件只能打开一个。
- **AI：** 给 AI 的说明只含软件里真正开放的工具；挑片和修图对话互不干扰；等你确认卡片的时间不再算进超时；确认卡片写明是哪张照片；停止或超时后不再留下“待确认”的假行。
- **界面：** 弹窗不再卡死在“正在处理”；按钮出错后不会一直灰着；撤销防连点；搜索词不再被冲掉；设置打开时不会被旧值冲掉。
- **设置与文件：** 工作文件夹所在盘暂时不在时设置不再被清空；设置/经验文件读坏时会备份并提示，不再被悄悄覆盖；WebView 临时文件改放 `%LOCALAPPDATA%\LatosHue\WebView2`，不再留在照片文件夹。
- **新增“旧版服务”检查：** 发现 0.11.x 等旧服务拖慢 Lightroom 时可一键结束。
- **插件：** 中文提示和中文路径在“西文区域”电脑上不再乱码或被拒。

### 怎么升级
1. 下载 `LatosHue-Setup-1.1.1.exe`，核对下面的 SHA-256。
2. **先关闭 Latos Hue 和 Lightroom**。
3. 双击运行安装包覆盖安装，设置和数据保留。
4. 装完重启 Lightroom，让插件更新到 1.1.1。

### 已知限制
- 只支持 Windows，需要 Lightroom Classic 和已登录的 Claude Code 或 Codex 命令行；安装包没有代码签名，SmartScreen 可能提示“未知发布者”，点“更多信息”→“仍要运行”。
- 尚未在真机上验证：LrHttp 在 Lightroom 里是否串行；并发取缩略图的长期稳定性；Codex 的修复；多个 AI 会话同时连接的表现；Windows 125% / 150% 缩放下的外观。
- 上表数字来自 15 张照片的测试目录，照片很多的目录会更慢。

### 给直接使用 MCP 服务的人
`LrMCP-Setup-v1.1.1.exe` 是单独的插件 + MCP 服务安装包，不含桌面软件；工具和用法不变。升级后在 Lightroom 里重载插件或重启。

## English

A fix-only release, no new features. Latos Hue (desktop app) and LrMCP (Lightroom plug-in and MCP server) share one version and one release; both installers are 1.1.1.

**Measured on a real machine (15-photo test catalog), 1.1.0 → 1.1.1:** select a photo 1.0–1.8 s → 0.03–0.19 s; first preview 4.1 s → 1.3 s; preview after an AI edit 3.7 s → 1.25 s; list gallery 1.0 s → 0.04 s; app start to "connected" 3.8–4.9 s → 1.0–1.8 s. Larger catalogs will be slower.

**What changed**
- Switching photos no longer forces Lightroom to change folder; the preview starts right after selection; thumbnails no longer block it.
- Long commands (e.g. big exports) are no longer mistaken for a disconnect; a missing/unlogged Claude no longer shows the whole Lightroom link as down; only one app instance can run.
- AI instructions list only the tools that are actually enabled; picking and editing use separate sessions; time spent on a confirmation card no longer counts toward the timeout.
- Dialogs no longer hang on "working"; buttons recover from errors; settings are no longer wiped when the work-folder drive is temporarily missing; unreadable settings/experience files are backed up instead of overwritten.
- New "old servers" check can stop leftover 0.11.x servers that slow Lightroom down.
- Plug-in: Chinese text and paths no longer break under non-UTF-8 locales.

**Upgrading:** close Latos Hue and Lightroom, run the installer over the old version (settings are kept), then restart Lightroom.

**Not yet verified on a real machine:** whether LrHttp is serial in Lightroom; long-run stability of concurrent thumbnail requests; the Codex fixes; several AI sessions at once; 125% / 150% display scaling. Installers are unsigned (SmartScreen may warn). Windows only. Licence AGPL-3.0-only; not an Adobe product.
